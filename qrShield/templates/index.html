Why QRShield

A normal QR code is just text. Anyone can print one that says ACCESS=ADMIN, and a scanner has no way to tell the difference. A signature fixes that.

Plain QR codeQRShield QR code
Who can create oneAnyoneOnly the holder of the private key
Can the data be editedYes, and nobody noticesNo. Any edit breaks the signature
What a thief gets from a photoThe whole secretA copy they cannot change
What the verifier needsBlind trustThe public key, which is safe to share

Where it fits Event tickets, building badges, boarding passes and certificates. Anywhere a code must be checked without trusting whoever is holding it.

Known limit A photographed QR still verifies, because a copy carries the same valid signature. Token expiry and replay protection are planned for that.

How the check works

  1. Sign The server hashes the data with SHA-256 and signs the hash with its private key.
  2. Encode The data and signature are packed into the QR code.
  3. Verify The public key confirms the signature matches the data exactly.
  4. Decide Match means access granted. Any change means access denied.
